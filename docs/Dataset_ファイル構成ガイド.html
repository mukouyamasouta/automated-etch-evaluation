2. まず持つべき全体像

Datasetは学習コードそのものではない。学習コードが「何を入力し、何を正解とするか」を定義する素材置き場である。

I
Images元SEM画像または切出しSEM画像。モデルへの入力。
＋
L
Labels基板=1、背景=0の二値マスク。U-Netの正解。
＋
C
CSV分割、パス、サイズ、ボックス座標を結ぶ索引。
→
M
ModelU-NetまたはFaster R-CNNがCSVを読み、必要ファイルを取得。

Original

画像全体。一枚に複数のエッチング構造を含む。物体検出では1画像が1サンプル。

Structure_padded

検出用座標に基づき、構造一つずつを余白付きで切り出した画像。手法BのU-Net入力。

Segmented

SEM画像ではなく二値マスクをFaster R-CNNの入力にする設定。手法Aに対応。

Four folders / zero overlap

Original・Structure_padded・Squared・Othersを
MECEに分解する

4つは同列の学習データではない。Originalは原本、Structure_paddedは最終手法B用の派生物、SquaredとOthersは旧方式の中間物である。以下では、役割が重ならない4軸で分類する。

01データの身分原本か、現行派生物か、旧実験物か
02画像の粒度全体SEMか、3構造単位か、1構造単位か
03生成元と生成方法手動アノテーションか、boxesによる切出しか
04使用フェーズ検出学習、U-Net学習、評価、旧検証のどこか
Canonical source
Original

切出し前の原本。データ系譜の出発点で、再生成の根拠。

1枚 ≈ 5構造
Canonical derivative
Structure_padded

Originalから構造単位で切り出した、手法BのU-Net用現行データ。

92枚 × 5 = 460構造
Legacy intermediate
Squared

1枚に3構造を含む正方形系。現行パイプラインの手前で試した方式。

258枚 × 3 = 774構造
Legacy derivatives
Others

774ペア × 2系統

全工程の再現元となる原本層

使わない場面構造ごとのU-Netに直接入力する場合。その役割はStructure_paddedが担う。

What it is for

各ファイル・フォルダは「何に使うものか」

ここではフォルダ名の説明ではなく、「どのモデルの、どの段階で、何のために使うか」を言い切る。ボタンで用途別に絞り込める。

Original/Images全体SEM
手法BのFaster R-CNN重み学習用。手法Aでは全体U-Netの入力にも使う。
なぜ：手法Bはセグメンテーションの前に、未加工のSEM上からエッチング構造の位置を見つける必要があるから。
対応：CSV_Data/Detection/Original/*.csv
Original/Labels全体マスク
手法AのU-Net重み学習用。手法BではStructure_padded/Labelsを作る切り出し元に使う。
なぜ：U-Netには各画素が基板か背景かを示す正解が必要である。手法B用切出しは、SEMと正解マスクに同じboxesを適用する。
対応：Segmentation/Original / Detection/Segmented
Structure_padded/Images切出しSEM
Structure_paddedは手法BのU-Net重み学習用であり、Imagesはその入力画像である。
なぜ：検出済みの1構造に範囲を絞ると、遠い背景や他の構造に影響されにくく、構造境界の学習に集中できるから。
対応：Segmentation/Detected_padded/*.csv の imgpath
Structure_padded/Labels切出しマスク
手法BのU-Netが予測すべき正解を教えるための教師データ。
なぜ：Imagesと完全に同じ矩形で切り出すことで、入力画像の各画素と正解クラスを1対1で対応させられるから。
対応：Segmentation/Detected_padded/*.csv の labelpath
CSV_Data/Detection/Original検出教師
手法BのFaster R-CNN重み学習用の索引。画像パス、クラス、boxes、分割を与える。
なぜ：Faster R-CNNは「その画像のどこに対象があるか」を矩形座標とクラスで学ぶため、TIFだけでは学習できないから。
入力先：Original/Images
CSV_Data/Segmentation/Detected_paddedU-Net索引
手法BのU-Net重み学習用のImages/Labels対応表。
なぜ：U-NetのDataLoaderが、どの切出しSEMとどの切出しマスクをペアにするか、どの集合で学習・選択・評価するかを知る必要があるから。
入力先：Structure_padded/Images / Labels
CSV_Data/Segmentation/Original手法A用
手法Aの全体U-Net重み学習用のImages/Labels対応表。
なぜ：手法Aは物体検出より先に全体SEMを二値化する。高解像度を保つため、学習時は全体画像からランダムクロップする。
入力先：Original/Images / Labels
CSV_Data/Detection/Segmented手法A用
手法AのFaster R-CNN重み学習用。元SEMではなく二値マスクを入力する。
なぜ：手法AではU-Netの出力後に構造の位置を検出するため、検出モデルも二値画像上の形状を学ぶ必要があるから。
imgpathはOriginal/Labelsを参照
Squared/Images + Labels旧中間粒度
3構造を1枚の正方形画像で扱う旧実験用。最終手法Bでは使わない。
なぜ作られたか：全体画像と1構造切出しの中間の粒度で、計算量、周辺文脈、検出難易度のバランスを試すためと考えられる。
対応：Detection/Squared / Segmentation/Squared
Others/Structure旧切出し
Squared画像内の3構造を1個ずつに分解する旧U-Net実験用。
なぜ：セグメンテーションを1構造単位で行う設計を、現行Structure_paddedより前のフローで試していたため。
注意：対応旧CSVの現行パスは切れている
Others/20250524Structure_padded旧改訂版
旧Structureの余白・切出し条件を改訂した比較実験用。
なぜ：切出しがタイトすぎると構造端が欠け、広すぎると不要背景が増えるため、切出し条件の改善を試す必要があった。
現行手法BのStructure_paddedとは別系統
Original/Labels_1 + Structure_padded/Labels_1別版教師
テストラベルの別版と比較するための補助データ。
なぜ：アノテーション修正や評価基準の変更後に、旧版と新版の結果を切り分けて比較するためと考えられる。

10. 自分の環境に構築するときの推奨形

元データは不変の原本として保存し、作業用データは別フォルダに複製する。参照切れや旧版混入を避けるため、初回トレースでは手法Bに必要な4組だけを抽出するのが安全である。

nojima-reproduction/ ├── README.md ← 出典、版、作業日、変更履歴 ├── data/ │ ├── raw/ ← 原本の読取専用複製 │ │ ├── images/ │ │ └── masks/ │ ├── detection/ │ │ ├── train.csv │ │ ├── val.csv │ │ └── test.csv │ └── segmentation/ │ ├── images/ ← 構造ごとの切出し │ ├── masks/ │ ├── train.csv │ ├── val.csv │ └── test.csv ├── src/ │ ├── prepare_data/ ← CSV生成・切出し・監査 │ ├── detection/ ← Faster R-CNN │ ├── segmentation/ ← U-Net │ └── inference/ ← End-to-End ├── configs/ ← パスとハイパーパラメータ ├── outputs/ ← 重み・ログ・推論結果 └── checks/ ← 整合性レポート

再構築のゲート

  • 版を固定： 論文の主実験を追試するか、マニュアルの最終配布版を再現するかを分ける。
  • 原本を保存： ネットワークボリューム上のDatasetを直接書き換えない。
  • CSVパスを統一： ../../Dataset/... を、構築先のルートから解決できるようにする。
  • ペアを検査： ImagesとLabelsのキー集合が一致することを学習前に自動確認する。
  • 分割を検査： train / val / testの元画像IDが交差しないことを確認する。
  • ボックスを検査： 画像範囲内、正の面積、labelsと個数一致を確認する。
  • 実験単位で分割： 切出し画像をランダム分割せず、必ず元SEM画像単位で分ける。
データ漏洩の典型例
Image_90_0 をtrain、Image_90_1 をtestに入れると、同じ元SEM画像の特徴が両方に入る。分割は必ず切出し前の 90 単位で行う。
